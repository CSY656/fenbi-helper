# 粉笔公考刷题助手 (Fenbi Helper Plus)

> **致谢与声明**：本项目基于原作者 [YSMull/fenbi-helper](https://github.com/YSMull/fenbi-helper) 进行深度二次开发与架构重构，补充了**行测在线全真刷题**、**申论真题研习与答题纸**、**外接大模型申论 AI 智能批改**及多项安全、性能与交互优化。感谢原作者的开源贡献！

---

## 🌟 核心升级与特性

### 1. 🤖 申论全真研习与 AI 智能批改（重磅新增）
- **真题长篇材料分栏阅读**：左侧展示完整试卷背景材料，支持**鼠标划词高亮标记**，方便提炼核心踩分点；
- **全真模拟答题纸**：严格字数限制提醒、实时动态字数统计、超限变红告警；支持 **LocalStorage 本地草稿自动保存**，刷新页面不丢答卷；
- **自定义大模型智能批改**：
  - 兼容 OpenAI 协议的任何模型，一键接入 **DeepSeek (DeepSeek-V3 / R1)**、**通义千问 (Qwen-Plus/Max)**、**GPT-4o** 或 **本地 Ollama 开源模型**；
  - **内置申论专业知识库（免 Key 也能用）**：未配置外部模型或外部调用异常时，自动无缝降级为内置知识库规则评分引擎；
  - **多维结构化诊断报告**：
    - 踩分点命中雷达（明确标出【已命中】与【未命中/遗漏】要点并逐条点评）；
    - 结构与逻辑诊断（小标题前置、归纳分类是否条理清晰）；
    - 语言规范与错词诊断（识别口语化表达，给出政论书面语替换建议）；
    - 专家升格示范重写（基于考生原本作答思路深度润色重构高分范文）；
- **历史批改归档**：历史批改记录自动落盘，答题纸右上角支持一键回看历史作答与评分对比。

### 2. 📝 行测在线全真刷题工作台（重磅新增）
- **双模式自由切换**：
  - **即做即判模式**：做完一题即刻判定正误，展示官方深度解析、全站难度星级；
  - **模考交卷模式**：独立计时器、答题卡即时标记作答进度，交卷后统一生成做题报告；
- **真题智能组卷与离线双重保障**：
  - 配置 Cookie 后优先智能同步粉笔题库真题或按模块检索组卷；
  - 离线或弱网下自动切换为内置五大模块（言语、判断、数量、资料、常识）经典真题，支持「再做一组」轮换刷题；
- **丝滑键盘快捷键**：
  - 键盘 `A` / `B` / `C` / `D` 快速选中对应项；
  - 键盘 `←` / `→` 快速切题；输入框聚焦时自动挂起快捷键防冲突；
- **生态联动**：支持一键收藏/取消收藏、查看题目视频解析与精选研讨。

### 3. 🛡️ 安全、可靠性与体验优化
- **凭据持久化与无感保活**：导入的粉笔 Cookie 自动持久化存储于本地数据目录，**重启服务无需重新导入**；
- **API Key 安全脱敏**：前端与接口仅传递脱敏掩码（如 `sk-d****7890`），不暴露明文 Key；未修改时自动沿用已存密钥；
- **并发池与性能缓存**：历史做题看板增加有限并发池（上限 6）与短期内存缓存，避免拉取上百条记录时触发粉笔接口风控；
- **自适应导航栏与 XSS 加固**：修复页面导航栏按钮折行问题，所有前端渲染节点做纯文本/安全标签过滤。

### 4. 📊 保留原版核心分析能力
- 做题历史分类复合看板与列表视图；
- 做题活跃度热力图（Cal-HeatMap）；
- 耗时分析、错题归类、做题时间轴；
- 单题视频播放、高赞笔记、查词造句与速算工具。

## 🚀 快速启动

### 方式一：本地 Node.js 运行

#### 1. 环境准备
- **Node.js** >= `18.0.0`（推荐 Node.js 20+）
- **npm** >= `9.0.0`

#### 2. 安装与启动
```bash
# 克隆代码
git clone https://github.com/CSY656/fenbi-helper.git
cd fenbi-helper

# 安装依赖
npm install

# 运行单元测试（校验核心逻辑）
npm test

# 启动服务（默认监听 3000 端口）
npm start
```

服务启动后，在浏览器访问：**http://localhost:3000**
（如需更换端口，可传入环境变量：`PORT=8080 npm start`）

---

### 方式二：Docker 容器运行

项目已升级为轻量级 `node:20-alpine` 容器镜像：

```bash
# 构建镜像
docker build -t fenbi-helper:latest .

# 启动容器并挂载数据目录（持久化配置与批改记录）
docker run -d -p 3000:3000 -v $(pwd)/data:/www/data --name fenbi-app fenbi-helper:latest
```

## 🛠️ 配置使用指南

服务首次启动后，建议先访问 **http://localhost:3000/setup** 完成以下两项配置：

### 1. 导入粉笔 Cookie（用于同步个人做题记录与行测题库）
1. 在浏览器打开并登录粉笔题库：[tiku.fenbi.com](https://tiku.fenbi.com)
2. 按 `F12` 打开开发者工具，切换到 **Network (网络)** 标签页；
3. 刷新页面，点击任一发往 `tiku.fenbi.com` 的请求（如 `category-exercises`）；
4. 在右侧 **Request Headers** 中找到 `Cookie:` 字段，复制其全部内容；
5. 粘贴到系统的「粉笔 Cookie 凭据」输入框中，点击「保存并验证 Cookie」即可。

### 2. 配置申论 AI 大模型（用于申论深度批改）
在设置页切换到 **「申论 AI 批改模型」** 标签页：
- **服务商预设**：支持一键切换预设模板：
  - **DeepSeek 官方 (推荐)**：Base URL 为 `https://api.deepseek.com`，模型填写 `deepseek-chat` 或 `deepseek-reasoner`；
  - **通义千问 (DashScope)**：兼容模式 Base URL，模型 `qwen-plus` 等；
  - **OpenAI 官方**：`https://api.openai.com/v1`，模型 `gpt-4o-mini` 等；
  - **本地 Ollama**：Base URL `http://localhost:11434/v1`，模型 `qwen2.5:7b`（无需 API Key）；
- 填写 API Key 后，点击 **「测试模型连通性」** 验证握手；
- 测通后点击 **「保存模型配置」** 即可生效。
> 即使暂不配置 API Key，申论答题纸依然会无缝使用内置的**启发式申论采分知识库引擎**进行模拟批改与出分。
